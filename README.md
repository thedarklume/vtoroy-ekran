# Второй экран

Телефон как второй монитор для ноутбука на Windows и удалённое управление ПК-ПК по коду.

Здесь лежат готовые версии программы (раздел Releases). Установленная программа сама проверяет этот репозиторий и предлагает обновиться.

Установка: скачать VtoroyEkran.zip из последнего релиза, разблокировать (Свойства -> Разблокировать), распаковать и запустить «Установить.bat».
